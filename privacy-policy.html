Local-first privacy AI Chat Vault is a local-first browser extension for transferring AI conversation context between supported AI chat websites. Conversation data is stored locally in the user's browser with chrome.storage.local. The extension does not send chat content to any external server. Exported JSON, TXT, PDF, or Markdown files are only read locally in the browser when the user imports them. Clipboard access is used only as a fallback when an AI website blocks direct prompt-box insertion. Website access is used only on supported AI chat sites to show the floating panel, read visible conversation text after a user action, and insert continuation prompts after a user action. User control Users choose when to save, export, import, copy, or delete conversation memory. Users can delete saved chats from the vault or remove the extension to clear its local storage. Contact For privacy questions, contact the publisher using the contact email listed on the Chrome Web Store listing.
